# Homebrew Tap

Homebrew formulae for [dortort](https://github.com/dortort) projects.

## Install

```sh
brew install dortort/tap/<formula>
```

For example, to install WaWarden:

```sh
brew install dortort/tap/wawarden
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [dgossgen](https://github.com/dortort/dgossgen) | Generate dgoss-ready test suites from Dockerfiles |
| [wawarden](https://github.com/dortort/wawarden) | Self-hosted WhatsApp gateway with per-client, per-chat access for AI agents |
